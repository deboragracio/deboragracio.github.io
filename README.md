# Débora Gracio — Technical Writing Portfolio

A Docusaurus-based professional portfolio for Débora Gracio.

## Stack

- Docusaurus 3.10.2
- React
- Markdown / MDX
- GitHub
- GitHub Pages

## Run locally

Requirements: Node.js 20 or later.

```bash
npm install
npm run start
```

The site will be available at `http://localhost:3000`.

## Build

```bash
npm run build
```

The generated static website is written to the `build/` directory.

## GitHub Pages

The intended repository name is `deboragracio.github.io`.

1. Create a new public repository named `deboragracio.github.io`.
2. Push this project to its `main` branch.
3. In GitHub, open **Settings → Pages**.
4. Set the build and deployment source to **GitHub Actions**.
5. The workflow in `.github/workflows/deploy.yml` will build and deploy the site.

The expected URL is `https://deboragracio.github.io`.

## Before publishing

- Review every employment description and confirm dates and wording.
- Confirm whether API documentation at fiskaltrust involved original authoring, review, maintenance, or a combination before making a specific claim.
- Confirm which employer and product names may be used publicly.
- Add original writing samples; do not upload confidential employer materials.
- Confirm the public contact details you want to display. The current draft includes your CV email address but intentionally omits your phone number.

## Content and confidentiality

Case studies are summaries of professional experience. They do not reproduce employer-owned documentation, internal screenshots, customer information, source code, or proprietary technical details.
