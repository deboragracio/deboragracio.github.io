# Cloud solution documentation

<small>Technical Writer · IBM · November 2021–September 2025</small>

## Context

Worked on technical documentation for IBM Cloud for VMware Solutions, supporting users and technical audiences working with cloud-based VMware environments.

## Documentation scope

- Product documentation and end-user guides.
- Troubleshooting content, release notes, FAQs, and system documentation.
- UX-related content, including UI text, design reviews, and user-facing messaging.
- Review and editing of administrator guides, architecture documentation, solution guides, and REST API documentation contributed by cross-functional teams.
- Technical illustrations and SVG assets.

## Collaboration

Partnered with product managers, software engineers, QA, UX designers, and architects throughout the software development lifecycle. Reviewed technical contributions for clarity, accuracy, consistency, and alignment with documentation standards.

## Additional initiatives

**Accessibility:** Led documentation accessibility reviews using Acrolinx, with a focus on accessibility standards and readability.

**Localization:** Coordinated automated translation workflows, localization deliveries, and reviews of translated content for style and formatting consistency.

## Tools and methods

Markdown · GitHub · Visual Studio Code · HTML · Figma · Inkscape · Sketch · Acrolinx · Monday.com · Slack · Agile/Scrum
