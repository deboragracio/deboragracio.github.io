# Point-of-sale system documentation

<small>Technical Writer · RADI – Restaurant Application Development International LLC · April 2014–July 2019</small>

## Context

Developed and maintained technical and end-user documentation for a point-of-sale system used in a large international restaurant environment.

## Documentation scope

- Translated developer specifications into structured documentation for technical and end-user audiences.
- Created and maintained user guides, technical materials, and help content.
- Produced diagrams, screenshots, and instructional media, including training videos.
- Maintained internal knowledge base content in Confluence.
- Coordinated documentation tasks, reviews, and workflows through Jira.
- Edited XML and HTML content used in documentation delivery and publishing.
- Prepared training materials for developers, QA engineers, business analysts, and technical writers.

## Approach

The role required understanding software behavior and translating technical specifications into practical information for different audiences. Documentation included both reference-oriented technical content and task-oriented user guidance.

## Tools

Microsoft Word · Help & Manual · Confluence · Jira · XML · HTML · Diagrams and instructional media
