# Developer documentation for fiscalization services

<small>Technical Writer · fiskaltrust · November 2025–present</small>

## Context

Working on developer documentation for software services in the fiscalization domain. The documentation supports developers and partners who need to understand products, configure integrations, and work with POS and backend systems.

## Scope of work

- Maintain and improve a developer documentation platform using Docusaurus and a Docs-as-Code approach.
- Create and maintain developer guides, onboarding content, integration workflows, and technical reference material.
- Collaborate with Engineering, Product, Legal, and subject-matter experts to clarify product behavior and validate content.
- Work with Markdown, GitHub, pull requests, reviews, and CI/CD publishing workflows.
- Use documentation analytics and search behavior to identify content gaps and improvement opportunities.
- Apply AI tools as assistants in research and drafting, while reviewing outputs for accuracy, consistency, and usefulness.

## Documentation practices

The work combines content development with platform and workflow improvements. Version control, peer review, automated builds, and continuous publishing help keep documentation aligned with product changes.

## Skills demonstrated

Docs-as-Code · Docusaurus · Markdown · GitHub · CI/CD · Developer documentation · Information architecture · SME collaboration · AI-assisted workflows
